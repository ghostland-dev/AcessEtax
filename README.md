# Energy Tax (AdonisJS)

AdonisJS rewrite of the E-Tax platform for energy tax files.

## Features

- Customs offices, NACE/NAF codes and electricity meter management
- Alerts and contacts modules
- TypeScript controllers and Lucid ORM models

## Tech Stack

- AdonisJS
- Shell
